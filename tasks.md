# Liste des tâches

- [ ] Créer un repository GitHub et le partager.
- [ ] Créer un programme en ligne de commande interactif en Python, Rust, TypeScript ou JavaScript — **2 pts**.
- [ ] Générer un entier aléatoire pouvant servir de seed sécurisée pour un wallet — **2 pts**.
- [ ] Représenter cette seed en binaire, bytes et hexadécimal, puis la diviser en groupes de 11 bits — **2 pts**.
- [ ] Associer chaque groupe de 11 bits à un mot de la liste BIP-39 et afficher la seed sous forme mnémonique — **2 pts**.
- [ ] Permettre l’import d’une seed mnémonique — **2 pts**.
- [ ] Vérifier les clés générées avec https://iancoleman.io/bip39/ — **2 pts**.
- [ ] Extraire la clé privée maître et le chain code — **2 pts**.
- [ ] Extraire la clé publique maître — **2 pts**.
- [ ] Générer une clé enfant — **2 pts**.
- [ ] Générer une clé enfant à l’index N — **2 pts**.
- [ ] Générer une clé enfant à l’index N au niveau de dérivation M — **2 pts**.
